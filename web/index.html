二、痛点与平台定位

现代低空威胁已由单架无人机上升为百架级智能无人机蜂群。典型"低慢小"目标（消费级多旋翼，约 10 m/s、15 m 量级目标特性）对末端防空构成现实威胁。受平台成本与载荷约束，单架拦截机速度难以对目标全面占优，面对高速机动目标单机拦截概率低。

本平台针对该痛点，支撑"以数量优势弥补速度劣势"的多机协同围捕方案（对应方案报告 3.5 节：《基于三维覆盖立体角的多拦截机协同围捕制导控制方案》），通过可复现的仿真、蒙特卡洛统计、代理模型与参数寻优，为总体单位回答"几架、多快、什么策略才能安全可靠地拦截目标"，并给出工程设计建议与性能包络。

三、核心技术：基于三维覆盖立体角的协同围捕

针对速度劣势（速度比 ρ<1）拦截机，以阿波罗尼斯球几何推导单架拦截机的三维覆盖立体角，把全包围条件由二维角修正为三维球面角，从而严格确定保证完全包围的最小编队规模：

半张角 sin α = ρ + R_c(1−ρ²)/d 覆盖立体角 Ω = 2π(1−√(1−sin²α)) 最小编队 n_min = ⌈4π/(η·Ω)⌉

再结合 拦截者—驱赶者动态角色分配（按 60° 角度阈值）与人工势场协同制导 + 机间避碰（软 50 m / 硬 10 m），实现速度劣势拦截机通过异步到达序贯封锁提高捕获成功率；围捕判定为至少 2 架进入 15 m 捕获半径。

创新点：把二维平面覆盖角升级为三维覆盖立体角，避免低估最小编队规模、防止三维空域围捕失效——这是本平台最核心的理论创新。

交叉验证：仿真最小编队 vs 三维覆盖最小编队

七、复现与平台架构

复现：pip install scipy scikit-learn matplotlib pyarrow；PYTHONPATH=src; python scripts/run_design_study.py 生成全部报告图与指标；PYTHONPATH=src; python web/app.py 启动本页面。

核心模块：solidangle.py（三维覆盖立体角→最小编队）、simulator.py（协同围捕仿真引擎）、study.py（设计空间采样/代理模型/约束寻优）、report.py（报告图与工程结论）。数据&图：data/outputs/design_study/。

所有数值均为平台实算所得，可通过同一随机种子复现，满足发榜单位"可复现、可核验"的评审要求。
